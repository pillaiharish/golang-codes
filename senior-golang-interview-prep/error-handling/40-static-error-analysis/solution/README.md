## Explanation and trade-offs

errcheck flags unchecked returned errors; staticcheck finds a broad set of correctness issues; go vet reports suspicious constructs. The nilness analyzer detects provable nil dereferences/conditions in supported analysis contexts. Tool availability varies: install separately.
