# Temporary Interview Reference Notes

This directory holds **company-neutral, temporary reference material** for interview preparation. It is intentionally separate from the permanent, concept-first study tracks in [`senior-golang-interview-prep/`](../senior-golang-interview-prep/README.md).

## Reference index

| Reference | What it covers |
|---|---|
| [Round 1 — Recruiter screen](round-1-recruiter-screen.md) | Expected questions, honest example answers, logistics, and questions to ask the recruiter |
| [Round 2 — Technical screen](round-2-technical-screen.md) | Coding, Go, Kubernetes, distributed systems, design, questions to ask, and a high-priority practice checklist |

## How to use these notes

1. Practice responses aloud **before** reading the examples.
2. Replace any placeholders with verified details from your own work; do not claim experience with a tool or responsibility you have only studied.
3. Treat the question lists as **possible practice prompts**, not a prediction or report of actual interviews.
4. Keep role-specific or recruiter-identifying information out of this directory. Move concepts worth retaining into the permanent study tracks after revision.

These are reference notes, not finished solutions or evidence of proficiency.
